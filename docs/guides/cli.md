# Заключения из командной строки

`launchers/cli/cli.py` формирует те же документы, что и «Сохранить как…» в окне заключения (без правок), — например,
для пакетной обработки. Нужен Python с пакетом `docxtpl`; OpenCRAVAT нужен только для того, чтобы найти настройки и свои
шаблоны (без него используются встроенные шаблоны).

```text
python launchers/cli/cli.py РЕЗУЛЬТАТ.sqlite [-m default|lpwgs|10x] [-t ОБРАЗЕЦ] [--template ID] [-o ПАПКА]
                                             [--conf-dir ПАПКА] [--no-ru-annotations]
python launchers/cli/cli.py --list-templates
```

| Параметр | Значение |
|---|---|
| `-m default` | стандартное заключение для каждого образца (по умолчанию) |
| `-m lpwgs` | целевой образец — стандартное заключение, остальные — документ LPWGS (как «Обработать как LPWGS») |
| `-m 10x` | документ LPWGS для каждого образца |
| `-t ОБРАЗЕЦ` | целевой образец в дуо/трио — как он называется в окне заключения (по умолчанию первый) |
| `--template ID` | шаблон стандартного заключения: `DZM`, `FND` или id своего шаблона (по умолчанию — из настроек, иначе DZM) |
| `-o ПАПКА` | куда сохранить `.docx` (по умолчанию текущая папка) |
| `--conf-dir ПАПКА` | папка настроек и своих шаблонов (по умолчанию — папка настроек OpenCRAVAT) |
| `--no-ru-annotations` | не загружать русские аннотации OMIM (без интернета) |
| `--list-templates` | показать доступные шаблоны и выйти |

Пример — трио, целевой образец `sample2`, режим LPWGS:

```text
python launchers/cli/cli.py trio1.sqlite -m lpwgs -t sample2 -o заключения
Saved заключения/Заключение (sample2).docx
Saved заключения/Заключение LPWGS (sample1).docx
Saved заключения/Заключение LPWGS (sample3).docx
```

Скрипт входит в исходный код (репозиторий), а не в приложение ClinReport. Чтобы взять свои шаблоны и врача из настроек
приложения, укажите его папку настроек: `--conf-dir %LOCALAPPDATA%\ClinReport\conf` (macOS:
`--conf-dir "~/Library/Application Support/ClinReport/conf"`).
