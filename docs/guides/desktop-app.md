# ClinReport на своём компьютере

Приложение ClinReport — это OpenCRAVAT вместе с окном заключения, собранные в одну программу для Windows и macOS.
Ничего больше ставить не нужно (ни Python, ни OpenCRAVAT), права администратора не требуются.

## Установка

Поддерживаемые системы, где скачать, установка на Windows 10/11 и macOS, обновление и удаление — в
[INSTALL.md](../../INSTALL.md).

## Работа

1. Запустите **ClinReport**. OpenCRAVAT сам не запускается: нажмите «Запустить» или просто откройте результат —
   OpenCRAVAT запустится и откроет его (первый запуск занимает до минуты). На вкладке «Обзор» видно, работает ли он.
   Браузер сам не открывается. Кнопки:

   - «Открыть» (синяя) — открывает OpenCRAVAT в браузере, когда он работает.
   - «Остановить» (красная) — пока OpenCRAVAT работает или запускается (прерывает запуск); после остановки на её месте
     «Запустить» (зелёная).

2. «Открыть результат…» (в карточке «Недавние результаты») — выберите файл `.sqlite`; он откроется в просмотрщике OpenCRAVAT в браузере. Можно также
   перетащить `.sqlite` на значок ClinReport.
3. В таблице вариантов отметьте нужные варианты в столбце **Note** (кнопка Note в карточке варианта → Save):

   | Note | Раздел заключения |
   |---|---|
   | `1` | Патогенный |
   | `2` | Вероятно патогенный |
   | `3` | Вариант с неизвестной клинической значимостью |
   | `7` | Вариант, не связанный с основным диагнозом |
   | `8` | Носительство |

4. На вкладке **Summary** в карточке *ClinReport* нажмите «Открыть окно заключения». Для недавних результатов есть
   короткий путь: кнопка «Заключение» рядом с результатом на вкладке «Обзор».
5. Выберите целевой образец (для дуо/трио) и нажмите «Обработать» или «Обработать как LPWGS».
6. Проверьте и при необходимости исправьте поля на вкладке каждого образца, выберите шаблон и нажмите «Сохранить как…».

Если вы изменили Note после обработки, нажмите «Обработать» ещё раз (правки в окне заключения при этом сбрасываются).

Закрытие окна ClinReport останавливает OpenCRAVAT: окно показывает «Завершение работы» и закрывается, когда
OpenCRAVAT остановлен (обычно за секунду-две; если идёт установка модулей в окружение — после неё).

## Настройки

Вкладка «Настройки»:

- **Врач** и **шаблон по умолчанию** — подставляются в каждое заключение (общие с окном заключения в браузере).
- «Запускать OpenCRAVAT при открытии ClinReport» (по умолчанию выключено), «Открывать OpenCRAVAT в браузере при запуске»
  (выключено), «Запускать при входе в систему» (свёрнуто, OpenCRAVAT запускается в фоне).
- **Порт** — автоматически (первый свободный, начиная с 8060) или постоянный.
- «Предлагать предварительные версии» — показывать тестовые выпуски (например, 3.1.0-rc1) как обновления.

Свои шаблоны заключений: вкладка «Шаблоны», см. [templates.md](templates.md).

## Окружения: свой OpenCRAVAT

Если на компьютере уже есть OpenCRAVAT (через pip, conda или его установщик), ClinReport может работать с ним, а не со
встроенным: тогда используются уже скачанные модули и базы, а задания лежат в привычной папке.

1. Вкладка **«Окружения»** → **«Найти окружения»**: ClinReport просмотрит обычные места (PATH, conda, pyenv, pipx,
   установленные Python, официальный установщик, запущенный OpenCRAVAT). **«Глубокий поиск»** просматривает все папки
   на дисках — дольше, его можно остановить. Если окружения нет в списке — **«Указать Python…»** и выберите `python.exe`
   (на macOS — `python3`) того окружения, где установлен OpenCRAVAT. Поиск ничего не меняет на компьютере.
2. Выберите окружение. Цветная плашка говорит, подходит ли оно и почему: версия OpenCRAVAT и Python, права на папку
   модулей, есть ли модуль `wgnote` (без него не отметить варианты в колонке Note).
3. **«Установить»** ставит модули ClinReport в папку модулей этого OpenCRAVAT. Если в нём не хватает пакетов для
   документов Word (`docxtpl` и др.), ClinReport скачает их в папку своего модуля — нужен интернет; пакеты самого
   окружения не меняются. Прежние модули сохраняются в резервной копии. **«Удалить модули»** убирает только папки ClinReport.
4. **«Использовать»** — OpenCRAVAT перезапустится уже из этого окружения; на вкладке «Обзор» будет видно его имя.
   Вернуться — выбрать «Встроенное» → «Использовать».

Шаблоны и настройки ClinReport общие для всех окружений. Если выбранное окружение пропало (его удалили, обновили до
неподходящей версии), ClinReport запустит встроенное и скажет об этом.

Ограничения: OpenCRAVAT 3.x в Windows запускается только встроенный (своему 3.x модули поставить можно); OpenCRAVAT
старше 2.2 не подходит; для OpenCRAVAT 2.x до 2.17 нужен `setuptools` младше 81.

## Обновление

Когда выходит новая версия, рядом с версией ClinReport на вкладке «Обзор» появляется кнопка:

- **Windows:** «обновить до X» → «Установить». ClinReport скачает установщик, закроется, обновится и запустится снова.
- **macOS:** «доступна X» открывает страницу выпуска; скачайте `.dmg` и замените программу в «Программах».

Можно и просто установить новую версию поверх старой. Настройки, свои шаблоны и задания OpenCRAVAT при обновлении
**сохраняются**: они лежат в папке данных, а не в папке программы.

## Где лежат данные

| Система | Папка |
|---|---|
| Windows | `%LOCALAPPDATA%\ClinReport` (например, `C:\Users\<имя>\AppData\Local\ClinReport`) |
| macOS | `~/Library/Application Support/ClinReport` |

Там настройки (`conf`), свои шаблоны (`conf\clinreport\templates`), задания OpenCRAVAT (`jobs`) и журналы (`logs`;
на macOS журналы лежат в `~/Library/Logs/ClinReport`, их видно и в программе «Консоль»).
Удаление программы эту папку **не** удаляет.

## Журналы

| Файл | Что в нём |
|---|---|
| `sessions/session-<дата>-<время>-<номер>.log` | один запуск целиком: версии системы и программы, ошибки окна и фоновых задач; хранятся последние 20 |
| `launcher.log` | главное из всех запусков подряд |
| `server.log` | вывод OpenCRAVAT за последний запуск (`server.log.1` — за предыдущий) |

## Если что-то не работает

- Вкладка «Журнал» → «Скопировать диагностику» и пришлите текст разработчику.
- Окно ClinReport пустое или не открывается: пришлите разработчику последний файл из `logs/sessions` (кнопка «Папка
  журналов» на вкладке «Журнал», или папка выше).
- «OpenCRAVAT не запускается»: перезапустите ClinReport; если порт занят другой программой, выберите в «Настройках»
  другой постоянный порт.
- Русские аннотации OMIM загружаются из интернета; без сети заключение строится с английскими (окно предупредит).
- Модули из магазина OpenCRAVAT (Store) ставятся с вкладки Store в браузере; если магазин недоступен (например, через VPN),
  на вкладке «Обзор» это видно.
