# Установка ClinReport

ClinReport — программа для Windows, macOS и Linux: OpenCRAVAT и окно заключения в одном установщике. Ничего больше ставить
не нужно (ни Python, ни OpenCRAVAT), права администратора не требуются.

## Какие системы поддерживаются

| Система | Файл | Размер |
|---|---|---|
| Windows 10 и 11, 64-битные | `ClinReport-<версия>-windows-x64.exe` | загрузка ≈ 75 МБ, на диске ≈ 370 МБ |
| macOS 10.15 Catalina и новее, процессор Intel | `ClinReport-<версия>-macos-x64.dmg` | загрузка ≈ 210 МБ |
| macOS 11 Big Sur и новее, Apple Silicon (M1 и новее) | `ClinReport-<версия>-macos-arm64.dmg` | загрузка ≈ 210 МБ |
| Linux x86-64: Debian 13, Ubuntu 24.04 и новее, Fedora 40 и новее | `ClinReport-<версия>-linux-x64.tar.gz` | загрузка ≈ 100 МБ, на диске ≈ 450 МБ |

Не поддерживаются: Windows 7 и 8, 32-битная Windows, macOS 10.14 и старше, Ubuntu 22.04 и Debian 12 (и старше).

Какой у вас Mac: меню  → «Об этом Mac». «Процессор … Intel» — файл `macos-x64`, «Чип Apple M…» — `macos-arm64`.

Интернет для работы не обязателен. Он нужен для русских аннотаций OMIM (без сети заключение строится с английскими)
и для установки модулей из магазина OpenCRAVAT.

## Где скачать

- **Выпуски:** страница [Releases](https://github.com/emijks/clinreport/releases) — файл для своей системы из раздела
  *Assets*.
- **Тестовые сборки** (для проверки до выпуска): [GitHub Actions](https://github.com/emijks/clinreport/actions) →
  нужный запуск *CI* → внизу страницы раздел *Artifacts*. Скачивание требует входа в GitHub; сборки хранятся 14 дней.

## Windows 10 и 11

1. Запустите `ClinReport-<версия>-windows-x64.exe`.
2. Если появилось «Система Windows защитила ваш компьютер» (SmartScreen), нажмите **«Подробнее» → «Выполнить в любом
   случае»**. Программа не подписана сертификатом — это ожидаемо.
3. Пройдите шаги установщика. Права администратора не нужны: программа ставится только для вас, в
   `%LOCALAPPDATA%\Programs\ClinReport`. Значок на рабочем столе — по желанию.
4. На последнем шаге оставьте галочку «Запустить ClinReport». Потом программа запускается из меню «Пуск» → ClinReport.

Первый запуск занимает до минуты: на вкладке «Обзор» должно появиться «OpenCRAVAT работает».

**Окно ClinReport пустое или не открывается (чаще на Windows 10).** Окно показывается компонентом Microsoft Edge
WebView2. В Windows 11 он встроен, в Windows 10 обычно приходит с обновлениями. Если его нет, скачайте *Evergreen
Bootstrapper* со страницы [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/), установите
и запустите ClinReport снова.

## macOS

1. Откройте `.dmg` и перетащите **ClinReport** в папку **«Программы»**. Запускать программу прямо из `.dmg` нельзя.
2. Снимите ограничение безопасности. ClinReport не заверен сертификатом Apple, поэтому macOS не даёт открыть скачанную
   программу. Откройте «Терминал» («Программы» → «Утилиты» → «Терминал»), вставьте команду и нажмите Return:

   ```sh
   xattr -dr com.apple.quarantine /Applications/ClinReport.app
   ```

   Команда снимает отметку «загружено из интернета» только с ClinReport; ничего не выводит, если всё в порядке. Если
   macOS пишет «Permission denied» (программу копировал другой пользователь), выполните её с `sudo ` в начале и введите
   пароль своей учётной записи.
3. Запустите ClinReport из «Программ» или Launchpad. Первый запуск занимает до минуты: на вкладке «Обзор» должно
   появиться «OpenCRAVAT работает».

Шаг 2 нужно повторять после каждой установки новой версии: новый файл снова получает отметку «загружено из интернета».

## Linux

Вся программа живёт в одной папке, `~/.local/share/clinreport`: сама программа, настройки, шаблоны, задания, кэш и
временные файлы. Снаружи — только значок в меню приложений и команда `clinreport`. Права администратора не нужны.

1. Распакуйте архив и установите (в терминале, из папки, куда скачан файл):

   ```sh
   tar xzf ClinReport-<версия>-linux-x64.tar.gz
   ./ClinReport/clinreport --install
   ```

   Программа скопируется в `~/.local/share/clinreport/app`, появится в меню приложений. Распакованную папку
   `ClinReport` и архив после этого можно удалить.
2. Запустите ClinReport из меню приложений (или командой `clinreport`). Первый запуск занимает до минуты: на вкладке
   «Обзор» должно появиться «OpenCRAVAT работает».

**Окно не открывается, а OpenCRAVAT открылся в браузере.** Окну нужна библиотека WebKitGTK; в GNOME она обычно уже
есть. Установите её и запустите ClinReport снова:

- Debian, Ubuntu: `sudo apt install gir1.2-webkit2-4.1`
- Fedora: `sudo dnf install webkit2gtk4.1`

**Окно пустое** (бывает в Wayland с видеокартой NVIDIA): запустите `WEBKIT_DISABLE_DMABUF_RENDERER=1 clinreport` и
сообщите разработчику.

Команды `clinreport` в терминале нет, хотя значок в меню есть: папка `~/.local/bin` попадает в PATH только после
повторного входа в систему; до этого — `~/.local/bin/clinreport`.

## Обновление

- **Windows:** ClinReport сам сообщает о новой версии («обновить до X» на вкладке «Обзор») и ставит её. Можно и вручную:
  запустите установщик новой версии поверх старой.
- **macOS:** «доступна X» открывает страницу выпуска. Скачайте новый `.dmg`, перетащите ClinReport в «Программы» с
  заменой и повторите шаг 2 (команду `xattr`).
- **Linux:** как в Windows — «обновить до X» → «Установить»: ClinReport скачает новую версию, закроется, заменит
  программу и запустится снова. Можно и вручную: распакуйте новый архив и выполните `./ClinReport/clinreport --install`.

Настройки, свои шаблоны и задания OpenCRAVAT при обновлении сохраняются.

## Удаление

- **Windows:** «Параметры» → «Приложения» → ClinReport → «Удалить».
- **macOS:** перетащите ClinReport из «Программ» в Корзину.
- **Linux:** в ClinReport «Настройки» → «Место на диске» → «Удалить ClinReport…» (галочка «Удалить также мои данные» —
  удалить всё), или в терминале:

  ```sh
  clinreport --uninstall            # программа, кэш, значок в меню; данные остаются
  clinreport --uninstall --purge    # всё, вместе с данными
  ```

  После `--purge` от ClinReport на компьютере ничего не остаётся (кроме строки в журнале использования приложений
  GNOME — его ведёт сама система для всех программ).

Данные пользователя при удалении остаются (в Linux — если не выбрано «удалить также мои данные»). Чтобы удалить и их,
удалите папки:

| Система | Данные | Журналы |
|---|---|---|
| Windows | `%LOCALAPPDATA%\ClinReport` | `%LOCALAPPDATA%\ClinReport\logs` |
| macOS | `~/Library/Application Support/ClinReport` | `~/Library/Logs/ClinReport` |
| Linux | `~/.local/share/clinreport` | `~/.local/share/clinreport/logs` |

## Если что-то не работает

Пришлите разработчику последний файл из папки журналов `sessions` (папки — в таблице выше; в ClinReport её открывает
кнопка «Папка журналов» на вкладке «Журнал»). На macOS папка `Library` скрыта: в Finder выберите «Переход» → «Переход к
папке…» (⇧⌘G) и введите `~/Library/Logs/ClinReport`.

Как работать с программой — [руководство](docs/guides/desktop-app.md).
